# Movie Rating Analysis

## Project Overview
This project analyzes movie ratings using Python and the MovieLens dataset. It explores movie popularity, user preferences, rating distributions, and genre performance through data analysis and visualization.

## Objectives
- Analyze the distribution of movie ratings.
- Identify the highest-rated movies.
- Find the most popular movies based on rating counts.
- Compare average ratings across genres.
- Analyze rating trends over time.
- Identify the most active users.
- Create visualizations and a dashboard.

## Dataset
**Source:** MovieLens Latest Small Dataset by GroupLens Research.

The dataset contains movie information, user ratings, and rating timestamps.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Load the MovieLens dataset.
2. Explore and clean the data.
3. Combine movie information with user ratings.
4. Analyze rating distributions and movie popularity.
5. Compare movie ratings across genres.
6. Examine rating trends over time.
7. Visualize the findings using charts and a dashboard.

## Visualizations
- Distribution of movie ratings
- Top-rated movies
- Most popular movies
- Highest-rated genres
- Average ratings over time
- Most active users
- Most popular genres
- Rating distributions across genres
- Movie Rating Analysis dashboard

## Results
The analysis identifies highly rated movies, popular genres, rating patterns, and user activity. The visualizations make these findings easier to understand.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells in order.
3. The dataset downloads automatically from the GroupLens website.
